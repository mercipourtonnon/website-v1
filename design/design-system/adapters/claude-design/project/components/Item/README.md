# Item

An Item: one row of a list — a leading mark, a title, a subtitle, a trailing value.

The `item` component type of the config.

## Don't

- It was named `list-item`; a config still writing `type: list-item` is refused with a message naming `item`, and renaming the `type` is the whole migration.

## Variants

- `default`
- `outline`
- `muted`
