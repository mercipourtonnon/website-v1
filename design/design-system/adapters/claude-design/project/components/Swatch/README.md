# Swatch

One colour drawn as a filled square with its value and its name.

The `swatch` component type of the config.

## Do

- Give it the token by **name** — a custom property under the name your stylesheet reads it by, such as `--primary`, `--background`, `--muted-foreground`, `--chart-1` or `--sidebar-primary`, or a step from a design ramp such as `neutral-500`.
- Use it for a role token, which is redeclared per scheme.
