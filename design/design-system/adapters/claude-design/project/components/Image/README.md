# Image

A picture with its alt text, lazy unless it is above the fold.

The `image` component type of the config.

## Do

- Give every image `width` and `height`: the browser then reserves its box before the file arrives and nothing below it moves — layout shift is the second of those metrics.
- Give every image that carries meaning a real `alt`.

## Variants

- `default`
- `avatar`
- `thumbnail`
- `hero`
