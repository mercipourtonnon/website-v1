# Badge

A Badge: a short status word pinned to a thing, never a sentence.

The `badge` component type of the config.

## Do

- Give it the two colours as token names or as literals — hex, `rgb()`, `oklch()`, `white`, `black` — and it reports the contrast ratio with its grade.

## Variants

- `default`
- `secondary`
- `destructive`
- `outline`
- `ghost`
- `link`
- `success`
- `warning`
- `info`
