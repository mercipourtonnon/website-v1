# InputOtp

A short verification code typed into an input OTP, one character per box, pasted or autofilled.

The `input-otp` component type of the config.

## Don't

- `inputType` is refused: an `input-otp` is always a one-time code.

## Anatomy

- `input-otp`
- `input-otp-group`
- `input-otp-slot`
