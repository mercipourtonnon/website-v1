# NumberInput

A number, typed or stepped one unit at a time.

The `number-input` component type of the config.

## Do

- Prefer `number-input` over an `input` with `inputType: number` when the value is genuinely counted — it gives keyboard and pointer affordances a text box does not.

## Anatomy

- `field`
- `field-label`
- `input-group`
- `input-group-addon`
- `input-group-button`
- `input-group-control`
