# Command

A Command palette: search everything from anywhere, opened with a keyboard shortcut.

The `command` component type of the config.

## Don't

- It was named `command-palette`; a config still writing `type: command-palette` is refused with a message naming `command`, and renaming the `type` is the whole migration.

## Anatomy

- `command`
- `command-input`
- `command-list`
- `command-group`
- `command-item`
