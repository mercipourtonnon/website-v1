# Empty

An Empty state: what a view says when it has nothing to show, and what to do about it.

The `empty` component type of the config.

## Don't

- It was named `empty-state`; a config still writing `type: empty-state` is refused with a message naming `empty`, and renaming the `type` is the whole migration.

## Anatomy

- `empty`
- `empty-header`
- `empty-title`
- `empty-description`
