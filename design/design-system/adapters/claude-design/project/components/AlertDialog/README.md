# AlertDialog

An Alert Dialog asking the reader to confirm an action that loses data.

The `alert-dialog` component type of the config.

## Do

- Use it for what cannot be undone — deleting an account or everything in a workspace — and make it something the reader knows, such as `$session.email` or `$record.name`, rather than a fixed word.

## Anatomy

- `overlay-frame`
- `alert-dialog-overlay`
- `alert-dialog-content`
- `alert-dialog-header`
- `alert-dialog-title`
- `alert-dialog-description`
- `alert-dialog-footer`
