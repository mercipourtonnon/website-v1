# Avatar

An Avatar: a person or a thing as a small round mark — a picture, initials, or nothing at all.

The `avatar` component type of the config.

## Don't

- `size` is `default` (32px) by default, with `sm` at 24px and `lg` at 40px — `md` is refused with a message naming `default`; `shape` is `circle` for people and `square` for a record or an organisation.

- `avatar-group`
- `avatar`
- `avatar-fallback`
