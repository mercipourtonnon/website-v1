# Code

A Code Block: source text in a monospace frame, highlighted by language, with a copy button.

The `code` component type of the config.

## Variants

- `default`
- `destructive`

## Anatomy

- `code-block`
- `code-block-header`
- `code-block-title`
- `code-block-filename`
- `code-block-actions`
- `code-block-copy-button`
- `code-block-content`
- `code-block-code`
- `code-block-line`
- `code-block-line-content`
